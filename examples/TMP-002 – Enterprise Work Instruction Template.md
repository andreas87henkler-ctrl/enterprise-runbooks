# 1. Purpose

This work instruction provides the technical implementation required to perform the operational procedure defined in the related Runbook.

It contains platform-specific commands, configuration steps, verification methods, and expected results.

---

# 2. Scope

This work instruction applies only to the specified platform or technology.

Alternative implementations shall be documented in separate Work Instructions.

# Template Notes

This template shall be used for all Work Instructions within the Enterprise Runbook Framework.

A Work Instruction describes **how** an operational procedure is technically implemented.

It complements the related Runbook, which defines **what** operational process shall be performed.

Platform-specific commands, configuration examples, screenshots, and technical procedures belong in the Work Instruction and shall not be included in the Runbook.
